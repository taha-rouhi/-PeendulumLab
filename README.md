# 📌 سیستم دیجیتال اندازه‌گیری شتاب گرانش ($g$) با آونگ نوری و پردازش سیگنال

این پروژه یک سیستم ابزاردقیق دیجیتال و ارزان‌قیمت برای اندازه‌گیری فوق‌دقیق شتاب گرانش زمین ($g$) است. در این سیستم از تلفیق سنسور مادون قرمز آنالوگ، مدار فیلتر سخت‌افزاری RC، ورودی کارت صدای رایانه به عنوان دیتالاگر با فرکانس بالا ($44.1 \text{ kHz}$) و پردازش سیگنال در پایتون استفاده شده است.

نتایج تجربی حاصل از این پروژه خطای میانگین کمتر از **۰.۴٪** و در بهترین حالت خطای خیره‌کننده **۰.۰۱٪** را در ثبت شتاب گرانش نشان می‌دهد.

---

## 🚀 ویژگی‌های کلیدی پروژه
- **دقت زمانی میکروثانیه‌ای:** استفاده از کارت صدا با نرخ نمونه‌برداری $44.1 \text{ kHz}$ به عنوان ADC، دقت زمان‌بندی را به ۲۳ میکروثانیه می‌رساند.
- **فیلترینگ آنالوگ سخت‌افزاری:** طراحی مدار فیلتر پایین‌گذر RC و تقسیم ولتاژ جهت حذف نویز لبه (Chattering/Bounce) و ایمن‌سازی ولتاژ خروجی برای کارت صدا.
- **اصلاح هندسی فیزیکی:** پیاده‌سازی فرمول‌های تصحیح اثر ابعاد فیزیکی گلوله (قطر بدنه) بر دوره تناوب واقعی آونگ در کد نرم‌افزار.
- **رابط کاربری گرافیکی اختصاصی (GUI):** طراحی محیط کاربری Native به صورت Dark Mode با کتابخانه `Tkinter` پایتون، نمایش زنده نمودار سیگنال و پیک‌های شناسایی شده و قابلیت تبدیل به خروجی مستقل `.exe`.

## 🛠 ساختار سخت‌افزار و مدار فیلتر RC
